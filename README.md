# Data Analize Compilator

Програма за Windows за обработка на отчети и бюджетни прогнози на РЗИ.

## Задачи (меню вляво)

| Таб | Какво прави |
|---|---|
| **Годишни отчети ЛЗБП** | Сравнява отчетите от новата година (365БО, Прил. 9, 11, 367, 369, 370, 372, Хоспитализации и др.) с една или няколко предходни години. Оцветява разликите: под 1% без цвят, 1–5% зелено, 5–10% жълто, над 10% червено. При посочване на клетката се вижда старата стойност. Лист „Разлики“ съдържа всички промени. |
| **Бюджетни прогнози ЛЗБП** | Проверява 10а (ОПР срещу Баланс, Актив = Пасив, Всичко разходи = Всичко приходи) и 12б срещу Баланса. Несъответствията са в червено. Обобщава 10а, 12б, 4а, 6а, 6б и 6в за ДЛЗБП и ОЛЗБП. |
| **Бюджетни прогнози общини** | Обобщава Приложение 7в от всички общини. Средната заплата се изчислява наново и се проверява във всеки файл. |

Резултатите се записват в папка до входната, със същото име и добавка **„ГОТОВИ“**.
Оригиналните файлове не се променят.

## Настройки
Стартиране с Windows, скриване до часовника при затваряне, известия, тема, граници на цветовете,
автоматично обновяване от GitHub.

## Нова версия
1. Смени `VERSION` в `app/__init__.py` и качи промяната в `main`.
2. GitHub Actions прави `DataAnalizeCompilator.exe` и го публикува. Програмата сама предлага обновлението.

## Ако Windows блокира .exe (Smart App Control)
Инсталирайте Python 3.12 от Microsoft Store и пуснете `install.ps1`. Програмата се слага в
`%USERPROFILE%\DataAnalizeCompilator`, с икона на работния плот, и се обновява сама.

## Стартиране от изходния код
```
pip install -r requirements.txt
python main.py
```
